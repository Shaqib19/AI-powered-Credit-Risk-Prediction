# AI Credit Risk Prediction Platform

An end-to-end AI-powered credit risk assessment system designed to help banks evaluate loan default risk efficiently.

## Project Overview
This project predicts the probability of loan default using machine learning and presents results through a secure, bank-focused web interface.

## Key Features
- Machine learning–based credit risk prediction
- Secure bank login & registration
- Token-based authentication
- Interactive dashboard for loan risk evaluation
- REST API built with FastAPI
- Frontend deployed on Netlify, backend on Render

## Tech Stack
- Python, SQL, HTML, CSS
- Scikit-learn, Pandas, NumPy
- FastAPI (Backend API)
- MySQL / SQLite (Authentication & data storage)
- Netlify (Frontend) & Render (Backend)

## Use Case
Banks can use this platform to assess applicant risk levels (Low / Medium / High) before approving loans, helping minimize defaults while maintaining healthy approvals.
